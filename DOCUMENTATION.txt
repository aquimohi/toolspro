CATEGORY 1: TEXT & SPEECH SUITE (3 TOOLS)
================================================================================

1. Word & Character Counter (`word-counter`)
   - Working Mechanism:
     * Regular Expression tokenization (`\s+`, `\b\w+\b`, `[.!?]`) se characters (with & without spaces), words, sentences, paragraphs, aur lines calculate karta hai.
     * 200–250 Words Per Minute (WPM) standard speed par silent reading time aur 130–150 WPM par speaking time estimate karta hai.
     * Flesch-Kincaid Reading Ease aur syllable count heuristics se text readability index calculate karta hai.
     * Real-time uppercase, lowercase, title case, camelCase, kebab-case, aur slug formatter provide karta hai.
   - Limitations:
     * Complex multi-lingual mixed text (Hindi, Urdu, Chinese characters + English) mein syllable count approximate hota hai.

2. Text & Diff Compare (Visual Diff 2.0) (`text-compare`)
   - Working Mechanism:
     * Myers Diff Algorithm (`diff` library) ka use karke text ko tokens (Words, Lines, Characters, Sentences ya JSON) mein decompose karta hai aur Shortest Edit Script (SES) compute karta hai.
     * Side-by-Side (Split) synchronized matrix, Unified Inline stream, Visual Merged Highlight, aur standard RFC `.diff`/`.patch` generate karta hai.
     * Mathematical Token Similarity ratio aur character delta calculate karta hai.
     * Standalone styled HTML aur .patch file download export support karta hai.
   - Limitations:
     * Ultra-large text files (100,000+ lines / 50MB+ continuous text) render karne par pure DOM painting mein minor delay aa sakta hai.
     * Physical scanned documents ko compare karne se pehle OCR run karna padta hai.

3. Text to Speech (TTS) (`text-to-speech`)
   - Working Mechanism:
     * Browser ke native `window.speechSynthesis` API aur `SpeechSynthesisUtterance` interface ka use karta hai.
     * Voice selection, playback rate (0.5x to 2.0x), pitch (0.0 to 2.0), aur volume controls apply karta hai.
   - Limitations:
     * Available voice qualities user ke Operating System (Windows, macOS, Android, iOS) aur browser engine par depend karti hain.
     * Offline speech synthesis OS ke installed local voice packs par nirbhar karta hai.

CATEGORY 2: AUDIO SUITE (4 TOOLS)
================================================================================

4. Audio Joiner & Merger (`audio-joiner`)
   - Working Mechanism:
     * Multiple audio tracks (MP3, WAV, AAC, OGG) ke ArrayBuffers ko `AudioContext.decodeAudioData()` se PCM Float32 audio channels mein decode karta hai.
     * Total length compute karke unhe continuous chronological timeline buffer mein append karta hai aur WAV format container mein encode karke download karata hai.
   - Limitations:
     * Badi audio files (100MB+) ko decode karne ke liye device ke browser RAM memory ka available hona zaroori hai.

5. Audio Speed Changer (`audio-speed`)
   - Working Mechanism:
     * Web Audio API `AudioBufferSourceNode.playbackRate` aur pitch-shift phase vocoder resampling ka use karke speed ko 0.25x se 3.0x adjust karta hai.
   - Limitations:
     * Extreme slow-down (0.25x se niche) par minor audio frame artifacting ho sakti hai.

6. Audio Volume Booster (`audio-volume`)
   - Working Mechanism:
     * Web Audio `GainNode` se audio buffer amplitude ko modulate karta hai aur dynamic range compression se decibel levels ko 0% se 300% boost/attenuate karta hai bina digital clipping ke.
   - Limitations:
     * Agar low-quality audio ko 300% boost kiya jaye toh pre-existing background noise bhi amplify ho jati hai.

7. Trim & Cut Audio (`audio-trim`)
   - Working Mechanism:
     * Live Canvas waveform generate karta hai. User dwara set kiye gaye start aur end millisecond timestamps ke according PCM buffer frames ko slice karke fresh WAV audio export karta hai.
   - Limitations:
     * Compressed lossy formats (MP3/AAC) decode hoke uncompressed PCM mein convert hote hain, isliye export lossless WAV mein hota hai.
